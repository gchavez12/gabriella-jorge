## Git Workflow

Steps of the Git workflow:
 - Collaborator edits file 
 - Collaborator commits and pushes file with new changes to Github 
 - Owner pulls the changes that the Collaborator made 
 - Owner edits file 
 - Owner commits and pushes file with new changes to Github 
 - Collaborator pulls the changes made by Owner 
 
## How to Create a Git Repository from an existing project
 
 - Navigate to your project folder using cd path/to/project
 - Initialize a Git repository with "git init"
 - Stage all files using "git add ."
 - Create first commit with "git commit -m "Initial commit""
